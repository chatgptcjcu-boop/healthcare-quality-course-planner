# 大四品質管理企劃教室｜逐段逐表填寫

以提供的 iCAP 報告書格式設計大四企劃案教學。每位學生個別填姓名、學號、年級、班級，選擇醫院或長照機構入職新人培訓主題。

## 21個獨立填寫步驟

封面；訓練需求；課程簡介；課程目的；時數、級別與對象；表1–12；課程發展佐證；利益關係人紀錄；PDCA；來源與AI揭露。

每個欄位獨立操作。表格是真正的逐欄逐列填寫表，支援新增／移除列、複選方法與設備、日期、人數和時數。每步都有「存檔」「下載本段備份」「上一段」「下一段」與模擬範例。支援整份備份匯入／下載、列印完整報告、段落必填與整份時數／任務／單元代碼檢查。

## 存檔方式

GAS 已部署於指定教師帳號。GitHub Pages 提供本機填寫與「開啟教師雲端存檔版」入口；要寫入 Google Sheet，請在雲端版填寫並輸入教師私下提供的課程代碼。

GAS 雲端版每段存到獨立工作表：每列含學生資料、企劃識別、時間、回執與各欄位。未填完可儲存草稿；完整提交需通過必填、時數與對應檢查。每次存檔保留版本，重送同一回執不重複寫入。

續填密鑰由學生瀏覽器產生，雲端只保存雜湊。讀回作業需要課程代碼、企劃識別和自己的續填密鑰；學生無法只憑學號讀取他人作業。教師仍需核對真實學籍。完整備份含續填密鑰，不能提供給別人。

教師帳號固定為 **chatgpt.cjcu@gmail.com**；setup 在其他帳號執行會拒絕建立資料。

## 維護

`schema.json` 為欄位來源；`template.html`、`app.js`、`validation.js` 為前端；`server.js` 為後端；`examples.json` 為模擬範例。執行 `python3 build.py` 生成公開頁面、Apps Script HTML、後端與單檔安裝稿。

執行 `node tests/server.test.cjs` 檢查收件與讀回權限。課程代碼、收件試算表識別與個人備份不寫入 GitHub。私人安裝稿放於 outputs（不提交）。

## 資料邊界

此系統是教學企劃工具，不是 iCAP 官方申請系統或認證。表2原格式留白，本版以單元地圖列實作；新增的任務代碼、PDCA和AI揭露是教學輔助欄位。各例全為模擬且尚未試辦，不代表臨床標準。證據採連結，不直接上傳個資檔案。教師需依校內規範告知保存期限並維持收件試算表私人權限。

教師編輯個案可選「教師／作者」身分，填寫作者姓名與主辦／規劃單位；學號與年級標示不適用。支援宮廟種子師資主題。完整備份可使用檔案匯入或「貼上備份內容」載入，兩者都不會自動提交。未知日期、實施人數與成果可留白，逐段存為草稿。
